# Attack Path Compiler

Manipal Hackathon 2026, Round 2. Raw security logs go in; a live graph comes out with ranked attack paths,
a plain-English story with ATT&CK technique ids and evidence per hop, and the cheapest fix that breaks the
dangerous paths. **All data is synthetic** (generated by EvidenceForge from `scenarios/stalk-branch.yaml`).

## How it works
`parsers` -> Event -> SQLite (append-only) -> `correlate` (events confirm inventory edges, raise p) ->
`analyze` (top-k paths by risk, cost-weighted min cut, greedy best single fix) -> FastAPI + SSE -> React/Cytoscape.
Contracts: `docs/contracts.md`. Risk = product(edge p) x target criticality / 10.

## Run
```bash
docker build -t apc . && docker run --rm -p 8000:8000 \
  -e SECRET_KEY=dev -e DEMO_USER=demo@example.com -e DEMO_PASSWORD=change-me -e COOKIE_SECURE=0 \
  -v apc-data:/var/lib/apc apc
# open http://localhost:8000 and press "Use demo account", then Play
```
Local dev: `cd backend && uv venv .venv && uv pip install -r requirements.txt && python -m pytest`;
`cd frontend && npm ci && npm run dev` (proxies `/api` to :8000).

## Environment
`PORT`, `STATIC_DIR`, `SEED_DIR`, `DATA_DIR`, `SECRET_KEY`, `DEMO_USER`, `DEMO_PASSWORD`, `COOKIE_SECURE`,
`ALLOWED_ORIGINS` (see `.env.example`). Deployment: `deploy.sh`, `docker-compose.yml`, `Caddyfile`.

## Ingest your own events
Create a key under Sources, then `POST /api/ingest` with `X-API-Key`. Formats: `linux_auth`, `web_access`,
`snort_alert`, or `events` (Event JSON).

## Limitations
Single-process SQLite; recompute is from scratch per batch (fine at demo size); edge priors in
`data/inventory.yaml` are hand-set.
